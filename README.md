## Overview

Arturia Clavinet V recreates the Hohner Clavinet D6, the clavichord-style electric keyboard that became the defining instrument of funk, known for its percussive, muted string attack.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Clavinet V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **String Model** | Physical modeling of clavichord strings and anvil contact mechanism |
| **Pickup Selection** | A, B, C, D pickup configurations matching the original switches |
| **Wah+Effects** | Built-in wah, EQ, and phase effects modeled on classic Clavinet signal chains |
| **Tuning** | Per-string tuning adjustment for detuned, chorused, or prepared sounds |
